# Pixel Time

An image search app built with plain HTML, CSS and JavaScript. You type a topic and it will show 20 matching images in a responsive grid (search is not implemented yet!).

**Design decisions**

\- I used a gradient title in a pixel-style font on a dark background, so the title stands out and the images stay the focus.

\- I added a result-count label under the search bar that doubles as an empty-state message, so new visitors know what to do before they've searched.
